# How to Access the New Innovation Competition Form

## 🎯 Quick Access URLs

### Option 1: Via Event Type Selection Page
```
URL: http://your-domain/organizer/events/create
```
This shows you the event type selection page with two cards:
- Innovation Competition
- Academic Conference

Click "Innovation Competition" card

### Option 2: Direct Access
```
URL: http://your-domain/organizer/events/create?type=innovation
```
This takes you directly to the Innovation Competition form

### Option 3: Via Events Dashboard
```
1. Login as Event Organizer
2. Go to "Events" menu
3. Click "Create New Event" button
4. Select "Innovation Competition" from the cards
```

## 🎬 Step-by-Step Demo Flow

### Example: Creating a Hybrid Event

**Step 1:** Navigate to create event
```
Click: Organizer Dashboard → Events → Create New Event
```

**Step 2:** Select Innovation Competition
```
Click: Innovation Competition card (red/orange gradient)
```

**Step 3:** Fill basic info
```
Title: "Tech Innovation Summit 2025"
Description: "Premier innovation competition..."
Venue: "Silicon Valley Convention Center"
City: "Santa Clara"
Max Participants: 200
Fee: 150.00
```

**Step 4:** Upload poster
```
Drag & drop your event poster
OR
Click "Click to upload" and select file
```

**Step 5:** Select Delivery Mode
```
Click: Hybrid (Both) option
→ Both F2F and Online sections appear
```

**Step 6:** Fill F2F details
```
F2F Start: March 10, 2025 @ 09:00
F2F End: March 12, 2025 @ 17:00
Paper Deadline: February 1, 2025
Product Deadline: February 15, 2025
Abstract Deadline: January 20, 2025
Acceptance Date: February 20, 2025
```

**Step 7:** Fill Online details
```
Online Start: March 5, 2025 @ 09:00
Online End: March 14, 2025 @ 17:00
Platform: https://zoom.us/j/123456789
Paper Deadline: February 10, 2025
Product Deadline: February 25, 2025
Abstract Deadline: January 25, 2025
Acceptance Date: February 28, 2025
```

**Step 8:** Submit
```
Click: "Create Innovation Event" button
→ Redirects to Events list
→ Success message: "Event created successfully!"
```

## 🔍 How to Find Your Created Events

After creating:
```
1. Go to: Organizer Dashboard → Events
2. Your event appears in the list
3. You'll see:
   - Event title
   - Delivery mode badge (F2F/Online/Hybrid)
   - Start date
   - Status
```

## 🎨 Visual Indicators

### Delivery Mode Display:
- **Face-to-Face**: 🏛️ Green badge
- **Online**: 💻 Blue badge  
- **Hybrid**: 🌐 Purple badge (both modes)

### Form Sections:
- **Active section**: Blue border highlight
- **Inactive section**: Hidden/collapsed
- **Required fields**: Red asterisk (*)

## 🛠️ Troubleshooting

### "Form not showing?"
✅ Make sure you clicked Innovation Competition (not Academic)  
✅ URL should contain `?type=innovation`

### "Sections not appearing?"
✅ Click on a delivery mode radio button  
✅ Sections appear dynamically based on selection

### "Validation errors?"
✅ Check all fields marked with * are filled  
✅ Ensure dates are valid (end after start)  
✅ If Hybrid: both F2F and Online sections must be complete
