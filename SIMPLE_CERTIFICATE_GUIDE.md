# 🎓 Simple Certificate System - Quick Guide

## ✨ What's New?

**NO MORE MANUAL POSITIONING!** The new certificate system uses pre-designed HTML templates. You just choose a design and customize colors - no X/Y coordinates needed!

## 🚀 How to Use

### Step 1: Access Certificate Management
1. Go to **Organizer Dashboard**
2. Click **Certificates** in the sidebar
3. You'll see all events with checked-in attendees

### Step 2: Customize Your Certificate
1. Click **"Manage Certificates"** for your event
2. Click **"Customize Template"** button
3. Choose from 4 professional designs:
   - **Classic** 🏛️ - Traditional elegant design
   - **Modern** ✨ - Clean contemporary look  
   - **Elegant** 👑 - Premium luxury style
   - **Minimal** 📄 - Simple and clean

### Step 3: Personalize Colors
- **Primary Color**: Main accent color (borders, title)
- **Secondary Color**: Supporting accent color
- **Text Color**: Main text color

### Step 4: Add Branding (Optional)
- **Logo**: Upload your organization logo (PNG recommended)
- **Signature**: Upload signature image
- **Signatory Name**: Name of person signing
- **Signatory Title**: Title (e.g., "Event Director")

### Step 5: Generate Certificates
1. Click **"Save Template"**
2. Go back to attendees page
3. Click **"Generate All Certificates"**
4. Done! All checked-in attendees now have certificates

## 📋 Features

✅ **Pre-designed templates** - Professional layouts ready to use  
✅ **Color customization** - Match your brand colors  
✅ **Logo support** - Add your organization logo  
✅ **Signature support** - Add authority signature

## 🎨 Template Styles

### Modern
- Sans-serif fonts (Helvetica, Arial)

- Clean and contemporary

### Elegant

- Gold/luxury color schemes
- Italic typography
- Best for: High-profile events, awards

### Minimal
- Simple line accent
- Light typography
- Lots of white space
- Best for: Modern events, startups

## 📍 Routes

- Events List: `/organizer/simple-certificates`
- Template Builder: `/organizer/simple-certificates/events/{event}/builder`
- Attendees: `/organizer/simple-certificates/events/{event}/attendees`
- View Certificate: `/certificates/{certificate}` (public)

## 🔄 Workflow

```
1. Event happens → Attendees check in
2. Organizer customizes template
3. Click "Generate All Certificates"
4. System creates certificate for each checked-in attendee
5. Attendees receive shareable certificate URL
6. They can view and print anytime
```

## ⚡ Quick Tips

- **Preview before generating**: Save template, then click Preview button
- **Colors matter**: Choose high contrast for readability
- **Logo size**: Keep under 2MB, PNG with transparent background works best
- **Signature**: Scan or digitize signature, save as PNG
- **Printing**: Use browser's "Save as PDF" feature for best results
